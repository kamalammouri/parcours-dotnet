# Parcours .NET

Cours .NET 10 / C# 14 à suivre à ton rythme, des bases de C# jusqu'à la création d'APIs avec ADO.NET, EF Core et ASP.NET Core. Base de données : SQL Server.

**Ouvrir le cours :** https://kamalammouri.github.io/parcours-dotnet/

## Le parcours

| Partie | Contenu |
|---|---|
| 1 · Fondamentaux .NET et C# | 6 chapitres, 67 leçons courtes : découvrir .NET, bases du langage, programmation orientée objet, types et mémoire, collections/génériques/LINQ, fichiers/JSON/asynchrone |
| 2 · SQL Server et ADO.NET | SQL, connexions, commandes, paramètres, transactions, procédures stockées, bulk, Dapper |
| 3 · Maîtrise d'EF Core | Modélisation, relations, migrations, requêtes, change tracker, concurrence, performance, tests |
| 4 · Créer des APIs avec ASP.NET Core | HTTP/REST, middleware, DI, controllers, Minimal APIs, validation, erreurs, OpenAPI, JWT, sécurité, tests |
| 5 · Architecture, patterns et tests | SOLID, Clean Architecture, design patterns, CQRS, DDD |
| 6 · Mise en production | Cache, jobs, Docker, CI/CD, entretien |
| Bonus | Performance, observabilité, SignalR, anti-patterns, documentation |

## Format d'une leçon (partie 1)

Une analogie « Pour comprendre », un cours court avec schémas, des exemples de code expliqués ligne par ligne avec le résultat console, trois exercices corrigés (facile, moyen, difficile), un mini-quiz et une étape du mini-projet Bibliothèque.

La progression est enregistrée dans le navigateur (localStorage), séparément sur chaque appareil.

## Structure

- `index.html` : l'interface et l'ordre du parcours (`PARTS`)
- `v2-ch*.js` : les leçons de la partie 1
- `n-*.js`, `week*.js` : les leçons des parties 2 à 6 et du bonus
